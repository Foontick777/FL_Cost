# FleetCost — stage 9.2 «Каунтеры на карточках + скролл» (редизайн 2)

## Что сделано (по вашей HTML-верстке)

Карточки авто/прицепов в разделах **Лизинг, Иные расходы, Страховка, Прицепы** переделаны с сумм на вкладках на вёрстку «gemini-code»:

1. **Каунтеры вместо сумм на вкладках**: «Разовые (7)» / «Регулярные (3)» — число ТРАНЗАКЦИЙ за выбранный период (не категорий и не договоров). Суммы больше не «поехали» бы при больших числах: точные суммы — в списке карточки, в подвале и в подсказке кнопки (tooltip).
2. **Карточки одного размера** (высота 356px): при любом числе платежей карточка не растёт и ничего не сдвигает — внутри появляется вертикальный скролл (проверено: 3 договора = 349px контента в окне 186px).
3. **Структурированная строка регулярного платежа**:
   - название + справа платёж **в месяц в валюте платежа**;
   - ниже срок действия («До 01.09.2027» или «Бессрочно») + день списания + «на паузе»;
   - ниже блок «Оплачено: N из M мес.» / «Осталось: K мес. · сумма (на текущую дату)» с мини-прогресс-баром (для бессрочных блок скрыт);
   - ниже «Списано за период: X EUR».
4. **Подвал карточки**: «Итого за период: N EUR» + слева «Разовые: X EUR», справа «Регулярные: Y EUR» (EUR-эквиваленты по сохранённым курсам операций). Итог не зависит от выбранной вкладки.
5. Группы разовых с числом операций: «Мойка ×3 — 65,80 EUR».
6. «Итого за период» унифицировано на всех 4 разделах (на страховке раньше было «Списано за период»).
7. Исправлен падеж: «Оплачено: 1 из 3 **месяцев**» (было «из 3 месяца»); для месячных — компактное «из 12 мес.» как на вёрстке.
